## 📋 O que tem aqui

### Guias de Workflow
Boas práticas e configurações recomendadas por tipo de produto e etapa do pipeline:
- **UV Mapping por tipo de produto** — automotivo, mobiliário, eletrônicos, CAD pesado
- **Substance Painter — Bake de AO** — configurações, troubleshooting, tabela de parâmetros

### Scripts e Automações
- **22+ scripts** organizados por categoria (Materiais, Meshes, Duplicatas, Texturas, UV, Limpeza, Export, Utilitários)
- **Busca por palavra-chave** e filtros por categoria
- **Botão de copiar** em cada script
- **Notas de uso** explicando o que cada script faz, quando usar e cuidados

## 🎯 Como usar

**Scripts:**
1. Acesse o [link da biblioteca](https://rfsfaria.github.io/scripts-blender/)
2. Encontre o script que precisa (use a busca ou os filtros)
3. Clique em **Copiar**
4. No Blender, abra a aba **Scripting** → **+ New** → cole o código → **Run Script**

**Guias:**
1. Acesse o mesmo link
2. Clique no card do guia para expandir (cards com "+")
3. Consulte as configurações recomendadas para o tipo de produto/etapa

## 🛠️ Workflow

Biblioteca interna criada para acelerar tarefas repetitivas no pipeline 3D do mK Studio:
- Imports CAD do DeltaGen
- Consolidação de materiais e geometria
- Detecção de duplicatas
- Otimização com InstaLOD
- UV mapping e bake de AO no Substance Painter
- Preparação e export de assets para o visualizador 3D (FBX, GLB com compressão Draco)
