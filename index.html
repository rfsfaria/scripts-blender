Duplicatas
Detectar duplicatas por hash de geometria (recomendado)
Método mais preciso de detecção. Compara a geometria real dos objetos vértice por vértice usando hash MD5 — falso positivo praticamente zero.

O que faz:

  • Calcula um hash único da geometria de cada objeto (posição real dos vértices no espaço mundial)
  • Agrupa objetos com hash idêntico (geometria 100% igual)
  • Mantém o primeiro de cada grupo e seleciona os demais para você revisar e deletar

Quando usar: quando os métodos mais simples deram muitos falsos positivos, ou quando você quer ter certeza de que está deletando apenas duplicatas reais.

Pega: ✓ peças sobrepostas exatas | Não pega: ✗ peças espelhadas | ✗ peças em array (posições diferentes)

Após rodar: as duplicatas ficam selecionadas. Confira no outliner e pressione X → Delete para remover.

import bpy
import hashlib

def hash_geometria(obj):
    """Gera um hash único baseado na geometria real do objeto."""
    mesh = obj.data
    
    # Coleta posições mundiais de todos os vértices
    matrix = obj.matrix_world
    vertices_mundiais = []
    for v in mesh.vertices:
        pos_mundial = matrix @ v.co
        vertices_mundiais.append((
            round(pos_mundial.x, 4),
            round(pos_mundial.y, 4),
            round(pos_mundial.z, 4),
        ))
    
    # Ordena para garantir mesmo hash independente da ordem
    vertices_mundiais.sort()
    
    # Cria hash MD5 da sequência
    dados = str(vertices_mundiais).encode('utf-8')
    return hashlib.md5(dados).hexdigest()

# Primeiro passo: filtra candidatos por contagem de vértices (rápido)
candidatos = {}
for obj in bpy.data.objects:
    if obj.type != 'MESH':
        continue
    chave_rapida = (len(obj.data.vertices), len(obj.data.polygons))
    if chave_rapida not in candidatos:
        candidatos[chave_rapida] = []
    candidatos[chave_rapida].append(obj)

# Segundo passo: nos grupos candidatos, calcula hash da geometria real
grupos_duplicados = {}
total_analisados = 0

for chave_rapida, objetos in candidatos.items():
    if len(objetos) < 2:
        continue
    
    for obj in objetos:
        total_analisados += 1
        hash_geo = hash_geometria(obj)
        if hash_geo not in grupos_duplicados:
            grupos_duplicados[hash_geo] = []
        grupos_duplicados[hash_geo].append(obj)

bpy.ops.object.select_all(action='DESELECT')
count = 0

print(f"=== Análise de {total_analisados} candidatos ===\n")
for hash_geo, objetos in grupos_duplicados.items():
    if len(objetos) > 1:
        print(f"Grupo ({len(objetos)} objetos com geometria idêntica):")
        print(f"  Mantido: {objetos[0].name}")
        for obj in objetos[1:]:
            obj.select_set(True)
            print(f"  Selecionado: {obj.name}")
            count += 1
        print()

print(f"\nTotal: {count} duplicatas selecionadas para deletar.")
print("Confira visualmente antes de pressionar X.")

Listar duplicatas por posição/rotação/escala
Método rápido que apenas lista (não seleciona) objetos com mesma transformação no espaço. Útil para fazer uma auditoria inicial.

O que faz:

  • Compara location, rotation e scale de todos os meshes
  • Lista no console os grupos de objetos com mesma transformação
  • Não seleciona nem deleta nada — apenas relatório

Quando usar: para um diagnóstico rápido de quantas duplicatas existem na cena antes de rodar o método de hash (que é mais pesado).

Limitação: ⚠ se você fez Apply Scale/Rotation nos objetos, esse método pode dar falsos positivos porque todos terão scale=(1,1,1) e rotation=(0,0,0).

import bpy

tolerancia = 0.0001

def chave_transform(obj):
    return (
        round(obj.location.x / tolerancia),
        round(obj.location.y / tolerancia),
        round(obj.location.z / tolerancia),
        round(obj.rotation_euler.x / tolerancia),
        round(obj.rotation_euler.y / tolerancia),
        round(obj.rotation_euler.z / tolerancia),
        round(obj.scale.x / tolerancia),
        round(obj.scale.y / tolerancia),
        round(obj.scale.z / tolerancia),
    )

grupos = {}
for obj in bpy.data.objects:
    if obj.type != 'MESH':
        continue
    chave = chave_transform(obj)
    if chave not in grupos:
        grupos[chave] = []
    grupos[chave].append(obj)

print("=== Possíveis duplicatas (mesma posição/rotação/escala) ===\n")
for chave, objetos in grupos.items():
    if len(objetos) > 1:
        print(f"Grupo com {len(objetos)} objetos:")
        for obj in objetos:
            print(f"  - {obj.name} ({len(obj.data.vertices)} vértices)")
        print()

Selecionar duplicatas para revisão visual
Versão intermediária — usa posição + contagem de vértices para detectar candidatos e seleciona as duplicatas (sem deletar) para você revisar visualmente.

O que faz:

  • Compara posição + número de vértices/faces (mais leve que o método hash)
  • Seleciona as duplicatas no viewport (mantém uma de cada grupo)

Quando usar: cenas pequenas/médias onde você quer revisar manualmente antes de deletar. Se a quantidade de falsos positivos for alta, use o método de hash.

Após rodar: abra o outliner, confirme as seleções e pressione X → Delete.

import bpy

tolerancia = 0.0001

def chave_obj(obj):
    return (
        round(obj.location.x / tolerancia),
        round(obj.location.y / tolerancia),
        round(obj.location.z / tolerancia),
        len(obj.data.vertices),
    )

grupos = {}
for obj in bpy.data.objects:
    if obj.type != 'MESH':
        continue
    chave = chave_obj(obj)
    if chave not in grupos:
        grupos[chave] = []
    grupos[chave].append(obj)

bpy.ops.object.select_all(action='DESELECT')
count = 0

for chave, objetos in grupos.items():
    if len(objetos) > 1:
        # Mantém o primeiro, seleciona os outros
        for obj in objetos[1:]:
            obj.select_set(True)
            count += 1

print(f"{count} duplicatas selecionadas para revisão.")
print("Verifique visualmente antes de deletar com X.")

Export
Exportar texturas como JPG otimizado
Exporta todas as imagens da cena em JPG com qualidade e resolução máxima configuráveis — útil para preparar texturas para o visualizador 3D (limite 2MB).

O que faz:

  • Percorre todas as imagens da cena
  • Redimensiona se forem maiores que o limite definido
  • Exporta como JPG na qualidade configurada para uma pasta de saída

Configurar: Ajuste pasta_saida, qualidade_jpg (0-100) e resolucao_max.

Atenção: o script redimensiona as imagens diretamente no .blend atual — salve um backup antes.

import bpy
import os

pasta_saida = "C:/Users/Rafael/Desktop/texturas_jpg/"
qualidade_jpg = 85  # 0-100, 85 é bom equilíbrio
resolucao_max = 2048

os.makedirs(pasta_saida, exist_ok=True)

bpy.context.scene.render.image_settings.file_format = 'JPEG'
bpy.context.scene.render.image_settings.quality = qualidade_jpg

for img in bpy.data.images:
    if img.source == 'GENERATED' or not img.has_data:
        continue
    
    if img.size[0] > resolucao_max or img.size[1] > resolucao_max:
        novo_w = min(img.size[0], resolucao_max)
        novo_h = min(img.size[1], resolucao_max)
        img.scale(novo_w, novo_h)
    
    nome_base = os.path.splitext(img.name)[0]
    caminho = os.path.join(pasta_saida, f"{nome_base}.jpg")
    img.save_render(filepath=caminho)
    print(f"Exportado: {nome_base}.jpg")

print("\nConcluído!")

Recalcula todas as normais para apontarem para fora — resolve faces invertidas (vermelhas no Face Orientation) em uma operação. Funciona muito bem em malhas CAD.

O que faz: aplica Mesh → Normals → Recalculate Outside (Shift+N) em todos os objetos selecionados de uma vez.

import bpy

for obj in bpy.context.selected_objects:
    if obj.type != 'MESH':
        continue
    bpy.context.view_layer.objects.active = obj
    bpy.ops.object.mode_set(mode='EDIT')
    bpy.ops.mesh.select_all(action='SELECT')
    bpy.ops.mesh.normals_make_consistent(inside=False)

import bpy

nome_material = "ALPHA ESTRUTURA PRO.002"

mat = bpy.data.materials.get(nome_material)

Join de todos os objetos por material (cena toda)
Agrupa e faz join de todos os objetos da cena que compartilham o mesmo material no primeiro slot — útil para consolidar geometria fragmentada de imports CAD.

O que faz:

  • Agrupa todos os objetos da cena pelo material do primeiro slot
  • Faz join automático de cada grupo com mais de 1 objeto
  • Mostra no console quantos grupos foram unidos

Atenção: salve o arquivo antes — operação afeta toda a cena de uma vez. O nome do objeto resultante vem do primeiro do grupo.

import bpy

def join_por_material():
    grupos = {}
    
    for obj in bpy.data.objects:
        if obj.type != 'MESH':
            continue
        if not obj.material_slots:
            continue
        mat = obj.material_slots[0].material
        if not mat:
            continue
        
        if mat.name not in grupos:
            grupos[mat.name] = []
        grupos[mat.name].append(obj)
    
    count_grupos = 0
    count_objetos = 0
    
    for nome_mat, objetos in grupos.items():
        if len(objetos) > 1:
            print(f"Juntando {len(objetos)} objetos com material: {nome_mat}")
            
            bpy.ops.object.select_all(action='DESELECT')
            for obj in objetos:
                obj.select_set(True)
            
            bpy.context.view_layer.objects.active = objetos[0]
            bpy.ops.object.join()
            
            count_grupos += 1
            count_objetos += len(objetos) - 1
    
    print(f"\nTotal: {count_grupos} grupos unidos, {count_objetos} objetos removidos.")

Consolidar materiais duplicados (.001, .002)
Detecta materiais com sufixos numéricos (.001, .002, .003) e consolida tudo no material base original. Útil para limpar duplicações que o Blender cria ao colar/importar.

O que faz: procura materiais com sufixos numéricos no nome e, se existir um material base sem sufixo, substitui todas as ocorrências do duplicado pelo original.

import bpy

def consolidar_materiais():
    count = 0
    materiais_consolidados = {}

    for mat in bpy.data.materials:
        if '.' in mat.name:
            partes = mat.name.rsplit('.', 1)
            if partes[1].isdigit():
                nome_base = partes[0]
                mat_base = bpy.data.materials.get(nome_base)
                if mat_base:
                    materiais_consolidados[mat.name] = mat_base

    for obj in bpy.data.objects:
        for slot in obj.material_slots:
            if slot.material and slot.material.name in materiais_consolidados:
                original = materiais_consolidados[slot.material.name]
                print(f"{obj.name}: {slot.material.name} → {original.name}")
                slot.material = original
                count += 1

    print(f"\nTotal: {count} slots consolidados.")
    print(f"Materiais únicos consolidados: {len(materiais_consolidados)}")

Consolidar instâncias de materiais com mesmo nome
Para casos onde múltiplos materiais têm o mesmo nome exato (datablocks separados). Mantém o de maior número de usuários e remove os órfãos.

O que faz: agrupa materiais que têm exatamente o mesmo nome, mantém o que tem mais usuários e substitui as demais ocorrências por ele. No final, remove os órfãos.

import bpy

def consolidar_por_usuarios():
    count = 0
    
    por_nome = {}
    for mat in bpy.data.materials:
        if mat.name not in por_nome:
            por_nome[mat.name] = []
        por_nome[mat.name].append(mat)
    
    for nome, mats in por_nome.items():
        if len(mats) > 1:
            principal = max(mats, key=lambda m: m.users)
            print(f"\nConsolidando: {nome} ({len(mats)} cópias, mantendo com {principal.users} usuários)")
            for obj in bpy.data.objects:
                for slot in obj.material_slots:
                    if slot.material in mats and slot.material != principal:
                        slot.material = principal
                        count += 1
    
    print(f"\nTotal: {count} slots consolidados.")
    bpy.ops.outliner.orphans_purge(do_recursive=True)

Join de objetos por nome base
Agrupa objetos com o mesmo nome base (ignorando sufixos .001, .002) e faz join automático em toda a cena.

O que faz: identifica objetos cujos nomes diferem apenas pelo sufixo numérico (.001, .002) e os une em um só. Útil para consolidar imports CAD onde a mesma peça vem em múltiplas instâncias.

Atenção: salve o arquivo antes — operação irreversível sem Ctrl+Z.

import bpy

def join_por_nome_base():
    count_grupos = 0
    count_objetos = 0
    
    grupos = {}
    for obj in bpy.data.objects:
        if obj.type != 'MESH':
            continue
        nome = obj.name
        if '.' in nome:
            partes = nome.rsplit('.', 1)
            if partes[1].isdigit():
                nome_base = partes[0]
            else:
                nome_base = nome
        else:
            nome_base = nome
        
        if nome_base not in grupos:
            grupos[nome_base] = []
        grupos[nome_base].append(obj)
    
    for nome_base, objetos in grupos.items():
        if len(objetos) > 1:
            print(f"Juntando {len(objetos)} objetos: {nome_base}")
            
            bpy.ops.object.select_all(action='DESELECT')
            
            principal = None
            for obj in objetos:
                obj.select_set(True)
                if obj.name == nome_base:
                    principal = obj
            
            if not principal:
                principal = objetos[0]
            bpy.context.view_layer.objects.active = principal
            
            bpy.ops.object.join()
            count_grupos += 1
            count_objetos += len(objetos) - 1
    
    print(f"\nTotal: {count_grupos} grupos unidos, {count_objetos} objetos removidos.")

Limpar geometria em múltiplos objetos
Aplica Merge by Distance e Delete Loose em todos os objetos selecionados — útil para limpar imports CAD em lote.

O que faz: para cada objeto selecionado, entra em Edit Mode e executa Merge by Distance (threshold 0.0001m) seguido de Delete Loose (remove vértices e edges órfãos). Sai do Edit Mode automaticamente.

Como usar: selecione os objetos que quer limpar antes de rodar o script.

import bpy

for obj in bpy.context.selected_objects:
    if obj.type != 'MESH':
        continue
    bpy.context.view_layer.objects.active = obj
    bpy.ops.object.mode_set(mode='EDIT')
    bpy.ops.mesh.select_all(action='SELECT')
    bpy.ops.mesh.remove_doubles(threshold=0.0001)
    bpy.ops.mesh.select_all(action='DESELECT')
    bpy.ops.mesh.select_face_by_sides(number=0, type='EQUAL', extend=False)
    bpy.ops.mesh.delete_loose()
    bpy.ops.object.mode_set(mode='OBJECT')
    print(f"Limpou: {obj.name}")

print("Concluído.")
UV/Seleção
Selecionar faces por ângulo da normal
Seleciona faces baseado no ângulo entre a normal e uma direção definida — útil para overhangs, faces voltadas para baixo, etc.

O que faz: calcula o ângulo entre cada face do mesh e o vetor de direção informado. Seleciona apenas as faces que caem dentro do range de ângulos especificado.

Configurar: ajuste direcao (vetor de referência), angulo_min e angulo_max. Precisa estar em Edit Mode com o objeto ativo.

import bpy
import bmesh
from mathutils import Vector

obj = bpy.context.active_object
bm = bmesh.from_edit_mesh(obj.data)

direcao = Vector((0, 0, -1))  # -Z (overhang)
angulo_min = 0  # graus
angulo_max = 45

for face in bm.faces:
    angulo = face.normal.angle(direcao) * 57.2958  # rad → graus
    if angulo_min <= angulo <= angulo_max:
        face.select = True

bmesh.update_edit_mesh(obj.data)
UV/Seleção
Selecionar arestas marcadas como Sharp
Seleciona todas as edges que têm a marcação Sharp (não baseada em ângulo, mas em mark sharp manual).

O que faz: percorre todas as arestas e seleciona as que estão marcadas como Sharp (independente do ângulo).

Atenção: precisa estar em Edit Mode com Edge Select Mode ativo.

import bpy
import bmesh

obj = bpy.context.active_object
bm = bmesh.from_edit_mesh(obj.data)

for edge in bm.edges:
    if not edge.smooth:  # edges marcadas como sharp
        edge.select = True

bmesh.update_edit_mesh(obj.data)

Limpar cache EXR corrompido (PowerShell)
Remove arquivos de cache do Compositor que podem corromper renders quando o nome da cena tem acentos.

O que faz: apaga todos os arquivos cached_RR_* da pasta Temp do Windows. Resolve travamentos do compositor após render quando há acentos no nome da cena.

Onde rodar: este é um comando do PowerShell do Windows, não do Blender. Abre o Terminal e cola.

Get-ChildItem "$env:TEMP\cached_RR_*" | Remove-Item -Force
