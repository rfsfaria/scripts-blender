+

Princípio geral

Não existe um método universal de UV que funcione bem para tudo. A escolha correta depende de três fatores: a topologia da malha (CAD vs modelagem orgânica), o tipo de produto (formatos convexos vs côncavos) e o uso final (bake de textura vs textura direta).

Regra prática: quanto mais complexa a malha (CAD de milhões de faces), mais robusto precisa ser o método de UV — nunca use Smart UV Project em CAD do DeltaGen.

Por tipo de produto

🚗 Automotivo (carroceria, portas, componentes de carro)

Método recomendado: Cube Projection

Por quê: peças de carro têm predominância de faces alinhadas a eixos ortogonais (laterais em Y, teto em Z, frente/traseira em X). O Cube Projection alinha as ilhas UV naturalmente com essas direções, gerando um layout previsível.

Bonus descoberto em projeto: em carrocerias com espessura de chapa CAD, o Cube Projection tende a separar automaticamente as faces internas das externas em ilhas distintas (porque projetam em direções opostas). Isso facilita muito identificar e deletar as faces internas depois.

Configuração:

  • Cube Size: 1.0 (ajuste se necessário)
  • Depois: UV → Pack Islands com margem 0.02–0.05

Evite: Smart UV Project em CAD de carro — cria milhares de ilhas microscópicas (uma por triângulo) e gera um atlas caótico.

🪑 Mobiliário (cadeiras, mesas, estofados)

Método recomendado: Smart UV Project com ajuste de ângulo, ou Unwrap com seams manuais

Por quê: mobiliário tem formas mais orgânicas/curvas (encostos, bases, braços) e o Smart UV lida bem com isso quando a malha já foi otimizada. Para peças estruturais mais simples (pernas, travessas), o Unwrap com seams manuais dá controle total.

Configuração Smart UV:

  • Angle Limit: 45°–66° (66° pega mais faces em cada ilha)
  • Island Margin: 0.01–0.03
  • Area Weight: 0.0

Configuração Unwrap com seams:

  • Marcar seams em dobras naturais (Ctrl+E → Mark Seam)
  • Seleciona tudo (A) → U → Unwrap
  • Estica ilhas suavemente com "Pin" se necessário
📦 Produtos gerais com formas geométricas (eletrônicos, embalagens)

Método recomendado: Cube Projection ou Unwrap com seams

Por quê: produtos como caixas, eletrodomésticos e eletrônicos têm faces predominantemente ortogonais. Cube funciona bem, mas se o produto tem faces angulares específicas, o Unwrap com seams manuais dá melhor controle.

⚠️ CAD pesado (imports do DeltaGen, SolidWorks, etc)

Antes de fazer UV: sempre otimize a malha primeiro.

  1. Merge by Distance com threshold 0.0001m (limpa vértices duplicados)
  2. Deletar faces internas se a peça tem "casca dupla" (script de detecção por normal)
  3. Aplicar Decimate ou InstaLOD para reduzir contagem de triângulos
  4. Só então fazer o UV
Atenção: tentar fazer UV em CAD com 4M+ de triângulos gera um atlas com milhares de ilhas minúsculas que é praticamente impossível de organizar bem. Sempre otimize antes.

Depois do UV — sempre fazer

  1. Pack Islands com margem adequada (0.02–0.05)
  2. Recalcular normais (Shift+N em Edit Mode)
  3. Conferir Face Orientation (todas azuis)
  4. Se houver seams visíveis marcadas em magenta no Substance, considerar refazer com seams manuais em pontos discretos

Armadilhas comuns

  • Ilhas muito juntas: geram sangramento de textura entre elas — aumente a margem
  • Ilhas muito pequenas: geram baixa resolução de textura naquela área — considere aumentar sua importância no pack (Area Weight) ou refazer o UV com escala manual
  • Bake Cage error: UV mal packeado causa problema no bake do Substance — mensagem típica é "UV overlap detected"
  • Seams em lugares visíveis: marque seams em dobras/vincos naturais, nunca no meio de uma superfície lisa

Pré-requisitos no Blender

Antes de exportar para o Substance, garanta que:

  1. Normais recalculadas (Shift+N em Edit Mode)
  2. Face Orientation limpo (todas as faces externas azuis)
  3. UV feito com método adequado ao produto (ver guia de UV)
  4. Merge by Distance aplicado (remove vértices duplicados)
  5. Escala aplicada (Ctrl+A → Scale) — evita problemas de tamanho no bake
Faces internas em CAD: se a peça tem "casca dupla" (superfície externa + interna com espessura), idealmente delete as faces internas antes de exportar. Se não der tempo, o Substance ainda consegue lidar bem com as configurações certas (abaixo).

Configurações recomendadas (Ambient Occlusion)

Ângulo de propagação 90° Rays só na frente da face, evita internas

Troubleshooting

Problema: Manchas pretas irregulares na superfície

Causa provável: faces internas ou normais invertidas geram sombras estranhas no AO.

Solução:

  1. Volta ao Blender, seleciona a peça
  2. Edit Mode → A → Shift+N (Recalculate Outside)
  3. Confere Face Orientation (tudo azul)
  4. Se ainda houver manchas, considere deletar faces internas
  5. Re-exporta e refaz o bake com Ignorar Face Traseira: Sempre
Problema: Linhas roxas/magenta nas seams do UV

Causa provável: transições entre ilhas UV visíveis no bake.

Soluções:

  • Aumentar Largura de dilatação para 64 ou 128
  • Ativar Suavização de borda (8x MSAA)
  • Refazer UV com Cube Projection (para carros) ou seams manuais
  • Se as linhas são finas e pouco visíveis, geralmente não são perceptíveis no produto final
Problema: Bake demora muito ou trava

Causa provável: malha muito pesada ou configurações agressivas demais.

Soluções:

  • Reduzir Qualidade para "Alto" ou "Muito Alto" (menos samples)
  • Reduzir Tamanho da saída para 2048 (ao invés de 4096)
  • Otimizar a malha no InstaLOD antes de bakear
Problema: AO parece "chapado" ou sem profundidade

Causa provável: intensidade baixa ou distância máxima curta demais.

Soluções:

  • Aumentar Intensidade AO para 1.0
  • Aumentar Distância máxima do oclusor para 0.5–0.7
  • Ajustar Ângulo de propagação para 120°

Workflow recomendado (ordem correta)

  1. Blender: otimização, UV, recálculo de normais, export FBX
  2. Substance: importar modelo
  3. Substance: configurar bake com valores da tabela acima
  4. Substance: primeiro bake em qualidade média para preview rápido
  5. Se preview OK: rebake em Ultra para versão final
  6. Se preview com problemas: ajustar Blender ou configurações antes de gastar tempo com Ultra

Observações finais

O Substance é notavelmente robusto ao lidar com malhas imperfeitas — muitas vezes um AO com pequenas manchas é aceitável no produto final, especialmente em áreas menos visíveis. Não gaste horas caçando perfeição pixel-a-pixel se o resultado no visualizador já ficou bom.

Regra do 80/20: concentre esforço nas áreas visíveis (superfícies externas, faces principais). Áreas ocultas atrás de outras peças no visualizador não precisam de AO perfeito.

Export
Exportar objetos visíveis como GLB individuais (com Draco)
Exporta cada objeto visível da cena como um arquivo GLB separado, com compressão Draco ativada — essencial para o visualizador 3D web.

O que faz:

  • Percorre todos os meshes da cena, ignora objetos ocultos no outliner (olho, monitor, collections fechadas)
  • Para cada objeto visível: exporta como GLB individual com compressão Draco sempre ativada
  • Sanitiza o nome do arquivo e restaura a seleção original ao final
  • Mostra relatório completo no console

Configurar:

  • pasta_saida — caminho de destino (use sempre /, nunca \)
  • exportar_sem_texturas — True para arquivo leve (recomendado, reaplica texturas JPG depois no visualizador), False para embutir tudo

⚠ Crítico: a compressão Draco está sempre ativada neste script (nível 6, quantization 14/10/12/10/12 — mesmos valores do painel padrão do Blender). Sem ela, o GLB fica muito mais pesado e o visualizador sofre.

import bpy
import os

# CONFIGURAR
pasta_saida = "F:/TRAMPO/METAKOSMOS/3Ds/Stellantis/Fiat Toro/Exports/Acessorios/Acessorios visualizador/"

# Se True, exporta sem texturas (arquivo bem mais leve para o visualizador)
exportar_sem_texturas = True

os.makedirs(pasta_saida, exist_ok=True)

# Guarda seleção atual
selecao_original = bpy.context.selected_objects[:]
ativo_original = bpy.context.view_layer.objects.active

def objeto_visivel(obj):
    """Checa se o objeto está realmente visível no viewport."""
    if obj.hide_get():
        return False
    if obj.hide_viewport:
        return False
    for collection in obj.users_collection:
        def checar_collection(layer_coll, alvo):
            if layer_coll.collection == alvo:
                return not layer_coll.hide_viewport and not layer_coll.exclude
            for child in layer_coll.children:
                resultado = checar_collection(child, alvo)
                if resultado is not None:
                    return resultado
            return None
        
        view_layer = bpy.context.view_layer
        visivel_na_coll = checar_collection(view_layer.layer_collection, collection)
        if visivel_na_coll is False:
            return False
    return True

count = 0
erros = []
ignorados = 0

export_image_format = 'NONE' if exportar_sem_texturas else 'AUTO'

for obj in bpy.data.objects:
    if obj.type != 'MESH':
        continue
    
    if not objeto_visivel(obj):
        ignorados += 1
        continue
    
    bpy.ops.object.select_all(action='DESELECT')
    obj.select_set(True)
    bpy.context.view_layer.objects.active = obj
    
    nome_arquivo = obj.name.replace('/', '_').replace('\\', '_').replace(':', '_')
    caminho = os.path.join(pasta_saida, f"{nome_arquivo}.glb")
    
    try:
        bpy.ops.export_scene.gltf(
            filepath=caminho,
            export_format='GLB',
            use_selection=True,
            export_image_format=export_image_format,
            export_apply=True,
            export_yup=True,
            export_texcoords=True,
            export_normals=True,
            export_materials='EXPORT',
            # Compressão Draco (mesmos valores do painel padrão do Blender)
            export_draco_mesh_compression_enable=True,
            export_draco_mesh_compression_level=6,
            export_draco_position_quantization=14,
            export_draco_normal_quantization=10,
            export_draco_texcoord_quantization=12,
            export_draco_color_quantization=10,
            export_draco_generic_quantization=12
        )
        count += 1
        print(f"Exportado: {nome_arquivo}.glb")
    except Exception as e:
        erros.append((obj.name, str(e)))
        print(f"Erro em {obj.name}: {e}")

# Restaura seleção
bpy.ops.object.select_all(action='DESELECT')
for obj in selecao_original:
    obj.select_set(True)
if ativo_original:
    bpy.context.view_layer.objects.active = ativo_original

print(f"\n=== Concluído ===")
print(f"Exportados: {count}")
print(f"Ignorados (ocultos): {ignorados}")
print(f"Sem texturas: {exportar_sem_texturas}")
print(f"Compressão Draco: ATIVA (nível 6)")
if erros:
    print(f"Erros: {len(erros)}")
    for nome, erro in erros:
        print(f"  - {nome}: {erro}")
Materiais
Limpeza completa de materiais e slots
Consolida materiais duplicados (por sufixo .001/.002 e por mesmo nome) e remove slots duplicados dos objetos — tudo em uma operação. Ideal após import do InstaLOD.

O que faz (3 etapas em sequência):

  • 1. Consolida materiais com sufixo numérico (.001, .002) no material base
  • 2. Consolida instâncias com mesmo nome (mantém o de mais usuários)
  • 3. Remove slots duplicados dos objetos e reatribui os índices das faces automaticamente
  • Ao final, remove materiais órfãos com orphans_purge

Quando usar: após import do InstaLOD (que costuma criar duas cópias do mesmo material com nomes idênticos), depois de importar FBX/OBJ de fontes externas, ou sempre que precisar limpar a estrutura de materiais.

Atenção: operação irreversível sem Ctrl+Z — salve backup do .blend antes. Preserva a atribuição de face por material (não bagunça UV nem shaders).

import bpy

def limpeza_completa_materiais():
    """
    Faz três operações em sequência:
    1. Consolida materiais com sufixo numérico (.001, .002) no material base
    2. Consolida instâncias com mesmo nome (mantém o de mais usuários)
    3. Remove slots duplicados dos objetos
    """
    print("=== LIMPEZA COMPLETA DE MATERIAIS ===\n")
    
    # ETAPA 1: Consolidar materiais com sufixo numérico
    print("[1/3] Consolidando materiais com sufixo (.001, .002)...")
    consolidados_sufixo = {}
    
    for mat in bpy.data.materials:
        if '.' in mat.name:
            partes = mat.name.rsplit('.', 1)
            if partes[1].isdigit():
                nome_base = partes[0]
                mat_base = bpy.data.materials.get(nome_base)
                if mat_base and mat_base != mat:
                    consolidados_sufixo[mat.name] = mat_base
    
    count_sufixo = 0
    for obj in bpy.data.objects:
        for slot in obj.material_slots:
            if slot.material and slot.material.name in consolidados_sufixo:
                slot.material = consolidados_sufixo[slot.material.name]
                count_sufixo += 1
    
    print(f"    {count_sufixo} slots consolidados (base sem sufixo)")
    print(f"    {len(consolidados_sufixo)} materiais únicos afetados\n")
    
    # ETAPA 2: Consolidar instâncias com mesmo nome
    print("[2/3] Consolidando instâncias com mesmo nome...")
    por_nome = {}
    for mat in bpy.data.materials:
        if mat.name not in por_nome:
            por_nome[mat.name] = []
        por_nome[mat.name].append(mat)
    
    count_instancias = 0
    for nome, mats in por_nome.items():
        if len(mats) > 1:
            principal = max(mats, key=lambda m: m.users)
            for obj in bpy.data.objects:
                for slot in obj.material_slots:
                    if slot.material in mats and slot.material != principal:
                        slot.material = principal
                        count_instancias += 1
    
    print(f"    {count_instancias} slots consolidados (mesmo nome)\n")
    
    # ETAPA 3: Remover slots duplicados dos objetos
    print("[3/3] Removendo slots duplicados dos objetos...")
    count_slots_removidos = 0
    objetos_afetados = 0
    
    for obj in bpy.data.objects:
        if obj.type != 'MESH':
            continue
        
        materiais_vistos = {}
        slots_para_remover = []
        remap = {}
        
        for i, slot in enumerate(obj.material_slots):
            mat = slot.material
            if mat is None:
                continue
            
            if mat.name in materiais_vistos:
                slots_para_remover.append(i)
                remap[i] = materiais_vistos[mat.name]
            else:
                materiais_vistos[mat.name] = i
                remap[i] = i
        
        if not slots_para_remover:
            continue
        
        if obj.data.polygons:
            for poly in obj.data.polygons:
                if poly.material_index in remap:
                    poly.material_index = remap[poly.material_index]
        
        bpy.context.view_layer.objects.active = obj
        for idx in sorted(slots_para_remover, reverse=True):
            obj.active_material_index = idx
            bpy.ops.object.material_slot_remove()
            count_slots_removidos += 1
        
        objetos_afetados += 1
    
    print(f"    {count_slots_removidos} slots removidos em {objetos_afetados} objetos\n")
    
    # Limpeza final
    bpy.ops.outliner.orphans_purge(do_recursive=True)
    
    print("=== CONCLUÍDO ===")
    print(f"Total de operações:")
    print(f"  - Slots consolidados por sufixo: {count_sufixo}")
    print(f"  - Slots consolidados por nome:   {count_instancias}")
    print(f"  - Slots duplicados removidos:    {count_slots_removidos}")

Duplicatas
Detectar duplicatas por hash de geometria (recomendado)
Método mais preciso de detecção. Compara a geometria real dos objetos vértice por vértice usando hash MD5 — falso positivo praticamente zero.

O que faz:

  • Calcula um hash único da geometria de cada objeto
  • Agrupa objetos com hash idêntico (geometria 100% igual)
  • Mantém o primeiro de cada grupo e seleciona os demais

Pega: ✓ peças sobrepostas exatas | Não pega: ✗ peças espelhadas | ✗ peças em array

Após rodar: confira e pressione X → Delete.

import bpy
import hashlib

def hash_geometria(obj):
    mesh = obj.data
    matrix = obj.matrix_world
    vertices_mundiais = []
    for v in mesh.vertices:
        pos_mundial = matrix @ v.co
        vertices_mundiais.append((
            round(pos_mundial.x, 4),
            round(pos_mundial.y, 4),
            round(pos_mundial.z, 4),
        ))
    vertices_mundiais.sort()
    dados = str(vertices_mundiais).encode('utf-8')
    return hashlib.md5(dados).hexdigest()

candidatos = {}
for obj in bpy.data.objects:
    if obj.type != 'MESH':
        continue
    chave_rapida = (len(obj.data.vertices), len(obj.data.polygons))
    if chave_rapida not in candidatos:
        candidatos[chave_rapida] = []
    candidatos[chave_rapida].append(obj)

grupos_duplicados = {}
total_analisados = 0

for chave_rapida, objetos in candidatos.items():
    if len(objetos) < 2:
        continue
    for obj in objetos:
        total_analisados += 1
        hash_geo = hash_geometria(obj)
        if hash_geo not in grupos_duplicados:
            grupos_duplicados[hash_geo] = []
        grupos_duplicados[hash_geo].append(obj)

bpy.ops.object.select_all(action='DESELECT')
count = 0

print(f"=== Análise de {total_analisados} candidatos ===\n")
for hash_geo, objetos in grupos_duplicados.items():
    if len(objetos) > 1:
        print(f"Grupo ({len(objetos)} objetos com geometria idêntica):")
        print(f"  Mantido: {objetos[0].name}")
        for obj in objetos[1:]:
            obj.select_set(True)
            print(f"  Selecionado: {obj.name}")
            count += 1
        print()

print(f"\nTotal: {count} duplicatas selecionadas para deletar.")
Duplicatas
Listar duplicatas por posição/rotação/escala
Método rápido que apenas lista (não seleciona) objetos com mesma transformação no espaço. Útil para auditoria inicial.

Limitação: ⚠ se você fez Apply Scale/Rotation, pode dar falsos positivos.

import bpy

tolerancia = 0.0001

def chave_transform(obj):
    return (
